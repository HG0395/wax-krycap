# 톡! 플레이 — 클리커 & 왁뿌볼

설치 없이 실행하는 한국어 미니 아케이드입니다. 클릭 포인트와 강화, 자동 적립, 4가지 색상의 왁스 파괴, 소리와 지원 기기의 진동을 제공합니다.

## 실행
`dist/index.html`을 브라우저에서 여세요. HTML, CSS, JS를 같은 폴더에 유지하세요.
게임 기록은 메모리에만 유지되며 새로고침하면 초기화됩니다. 자동 적립은 페이지가 보일 때만 진행됩니다.

## Cloudflare Pages
- 연결 저장소: HG0395/wax-krycap
- 프로덕션 브랜치: main
- 프로젝트 루트: 저장소 루트
- 프레임워크: None
- 빌드 명령: 비워 두거나 `exit 0`
- 배포 출력 폴더: `dist`
- `wrangler.jsonc`에 출력 폴더를 선언했습니다.

루트 URL이 404이고 `/dist/`만 열린다면 저장소 루트가 잘못 배포된 것입니다. Pages의 Settings → Build 설정에서 출력 폴더를 dist로 지정하고 재배포하세요. 프로젝트 루트를 dist로 지정했다면 출력 폴더를 다시 dist로 중첩하지 마세요.

## 콘텐츠와 접근성
- 게임과 같은 페이지에 실제 규칙·강화 비용표·파괴 방식·조작 안내 제공
- 고유한 FAQ, 사이트 소개, 데이터 처리 안내, 실제 GitHub 오류 제보 링크
- 본문 바로가기, 키보드 조작, 진행률 이름, 명확한 게임 선택 상태
- 중복 문서나 광고 유도 페이지 없이 하나의 게임 서비스에 집중
- Google 애드센스 연결 코드와 루트 ads.txt 포함; 별도 게임 분석 도구·로그인 폼 없음

## 검증
Node.js에서 `node verify.cjs`를 실행하세요. 클릭 보상, 강화, 파괴, 진동의 지원·거부·실패 상황과 키보드 범위, 내부 링크, 콘텐츠와 가격의 일치를 확인합니다.
실제 기기의 진동 여부는 기기와 브라우저에서 별도로 확인해야 합니다.
